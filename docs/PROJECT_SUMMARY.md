# Pilihos 项目总结

## 项目概述
Pilihos 是一个基于 HarmonyOS（鸿蒙）系统的 Bilibili（哔哩哔哩）第三方视频客户端，使用 ArkTS 语言开发。

## 主要功能
1. **首页推荐**：展示个性化推荐视频流，支持下拉刷新和上拉加载更多
2. **视频播放**：支持竖屏详情页播放和横屏全屏播放，使用原生 XComponent 组件
3. **用户系统**：通过 Bilibili 官方页面登录，支持 Cookie 认证和会话持久化
4. **个人中心**：展示用户信息、动态、关注、粉丝等统计数据
5. **消息中心**：显示回复、@我、点赞、系统通知等消息分类
6. **搜索功能**：支持视频搜索
7. **设置页面**：外观设置、播放器设置等

## 技术架构
- **开发语言**：ArkTS（HarmonyOS 原生语言）
- **UI 框架**：ArkUI（声明式 UI）
- **网络请求**：使用 HarmonyOS HTTP 客户端
- **视频播放**：原生 XComponent + 自定义播放器服务
- **数据存储**：Preferences（轻量级存储）
- **安全机制**：HUKS 密钥管理、Wbi 签名算法

## 项目结构
```
Pilihos/
├── entry/src/main/ets/
│   ├── pages/          # 页面组件（Index.ets, Settings.ets）
│   ├── services/       # 业务服务（认证、推荐、播放等）
│   ├── models/         # 数据模型（VideoItem）
│   ├── utils/          # 工具类（ImmersiveMaterial）
│   └── entryability/   # 应用入口
├── resources/          # 资源文件
└── pilihoszs/          # 签名证书
```
